# Omnidirectional Forklifter

An omnidirectional forklift robot designed for material handling in tight
industrial and warehouse spaces, where a conventional forklift cannot turn
easily.

## Overview

The robot uses a holonomic (omnidirectional) drive, so it can move forward,
sideways and diagonally and rotate in place — positioning the forks precisely
without multi-point turns. A lift mechanism raises and lowers the load on the
forks.

## Key features

- Holonomic movement — strafe, diagonal travel and in-place rotation
- Fork lift mechanism for picking and placing loads
- Compact chassis designed for narrow aisles and indoor floors
- Mechanical design and prototyping done in SolidWorks
